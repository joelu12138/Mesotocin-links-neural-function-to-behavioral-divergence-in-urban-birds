# Mesotocin-links-neural-function-to-behavioral-divergence-in-urban-birds
R analysis code for a study of how urbanization reshapes neural organization and mesotocin (MT) signaling in Eurasian tree sparrows: behavioral, histological and electrophysiological statistics, snRNA-seq and Stereo-seq spatial transcriptomics, hdWGCNA, CellChat, and MT/oxytocin/NMDA pharmacology.
